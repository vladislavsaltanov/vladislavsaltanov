**1. PunchUp — 2D рогалик-платформер**                                                                                                                                                     
https://github.com/vladislavsaltanov/PunchUp                                                                                                                                           
                                                                                                                                                                                        
Стек: C#, Unity, FMOD.                                                                                                                                                                 

Игра с пиксельной графикой, звуком и собственными саундтреками. Герой, енот Рикки, поднимается по Башне через Лабораторию и Виварий. Каждый забег генерируется заново. Предметы четырех тиров редкости меняют стиль игры, на нечетных этажах работает магазин, враги становятся сильнее чем дольше забег. В финале ждет Тесей. У проекта был свой сайт с общей статистикой и скачиванием, вики с лором и телеграм-канал. Командная работа шести человек со второго и первого курсов.

**2. ARIA — аудиоплеер для мероприятий**                                                                                                                                                   
https://github.com/vladislavsaltanov/ARIA                                                                                                                                              
                                                                                                                                                                                        
Стек: C# (.NET 10, Avalonia UI), C (нативный шим на miniaudio), SQLite.                                                                                                                
                                                                                                                                                                                        
Десктопный плеер для звукорежиссеров. Один Deck «текущий + следующий», кроссфейд внутри микшера, очередь поверх плейлиста, точки Cue in/out, маркеры с автостопом, превью трека на канале прослушки. PANIC глушит зал и прослушку фейдом до 100 мс, восстановление только вручную. Сценарная панель со временем шоу и упоминаниями треков, исполнение строки ставит трек в очередь. Пульт из браузера по локальной сети: HTTP + WebSocket, pairing по идентификатору и паролю, QR и mDNS. Библиотека и кэш волн в SQLite, автосейв шоу каждые 500 мс. Форматы WAV, FLAC, MP3, OGG, движок 48 кГц стерео. Self-contained сборки под четыре платформы, сборка с нулем предупреждений.

**3. QuizForum — открытый банк вопросов**
https://github.com/vladislavsaltanov/QuizForum                                                                                                                                         

Стек: Ruby 4.0.7, Rails 8.1, PostgreSQL, Hotwire (Turbo + Stimulus), Docker + Kamal, Python-sidecar.                                                                                   
                                                                                                                                                                                        
Автор публикует вопрос со скрытым эталоном и дедлайном, остальные отвечают вслепую. До дедлайна видны только личности ответивших, после происходит автораскрытие: эталон, все попытки, вердикты, комментарии. Типы ответов: текст, код, одиночный и множественный выбор. Вердикты: pending, correct, partial, incorrect. Текст оценивает внешнее жюри OpenJev, код гоняет отдельный CodeRunner на восьми языках, сравнивая эталон и решение на общих тестах. Модерация через Laya до записи в базу, сомнительные комментарии висят в pending. Есть роль Trustee с доступом к одному вопросу, вход по паролю и через Google, подтверждение почты. Рейтинг считается по числу correct на раскрытых вопросах. Каждый день в 17:00 падает пак из девяти ИИ-вопросов от Gemini с баннером на главной и архивом с автоудалением.

**4. Paages — заметки с деревом папок**                                                                                                                                                
https://github.com/vladislavsaltanov/Paages

Стек: C# (.NET 10), Blazor Server, EF Core + SQLite (WAL), Quill 2.0.2, highlight.js, MailKit. Лицензия AGPL-3.0.                                                                      
                                                                                                                                                                                        
Вместо тегов иерархия папок с drag-and-drop, контекстным меню, вкладками и хлебными крошками. Редактор форматирует markdown прямо при вводе и вставке, сырая разметка открывается при выделении, автосохранение с дебаунсом 1.5 секунды. Подсветка синтаксиса в код-блоках работает и в публичном просмотре. Два процесса, Web и Api, живут над общей базой. Аутентификация: JWT access/refresh с ротацией и детектом переиспользования, cookie-вход, Google OAuth, подтверждение почты, сброс пароля, именованные Personal Access Token. Публикация заметки дает ссылку для чтения без авторизации. Покрыт 72 unit-тестами на SQLite in-memory, дальше в roadmap настройки, тесты API, экспорт и мобильная адаптация.

**6. Queuer — живая очередь в Telegram**                                                                                                                                                   
https://github.com/vladislavsaltanov/Queuer                                                                                                                                            
                                                                                                                                                                                        
Стек: C# (.NET 10), Telegram Bot API, Docker, JSON-файл состояния.                                                                                                                     
                                                                                                                                                                                        
Одно сообщение со списком вместо спама «кто последний», один процесс ведет несколько чатов. Админ открывает очередь командой, участники встают и выходят кнопками, список обновляется на месте. Обмен местами идет через предложение с кнопками Yes/No, без ответа за пять минут оно сгорает. Первый в списке получает уведомление «Ваша очередь», которое висит 15 секунд и удаляется. Очередь живет три часа, за десять минут до конца бот спрашивает админа про продление. Ошибки показываются всплывающим окном без лишних сообщений. Состояние лежит в data/queues.json и переживает рестарт, деплой одной командой через Docker Compose.

**7. hermes-vk-bot — VK-фасад для Hermes Agent**                                                                                                                                           
https://github.com/vladislavsaltanov/hermes-vk-bot                                                                                                                                     
                                                                                                                                                                                        
Стек: Ruby 3.4, VK Long Poll API 5.131, SQLite, RSpec + RuboCop, Docker, GHCR-деплой по SSH.                                                                                           
                                                                                                                                                                                        
Бот сообщества ВКонтакте, через который общаются с Hermes Agent. Главное меню с кнопками, несколько сессий диалога на выбор, очистка истории с подтверждением, индикатор «печатает» пока ждет ответ. Внутри конечный автомат состояний, история и состояние пользователя в трех таблицах SQLite, перезапуск ничего не теряет. Доступ строго по белому списку user_id, сетевые сбои VK переживает ретраями. CI гоняет линтер и тесты, деплой на сервер идет автоматом после мержа в main.
